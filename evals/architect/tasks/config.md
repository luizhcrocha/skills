Design the configuration loader for one small TypeScript HTTP service. Settings come from environment variables and an optional TOML file (the env var wins). There are about fifteen settings: a port, a database URL, a log level, a few feature flags, two API keys, some timeouts. A bad or missing required setting must stop the service at startup with a message that names it. Operators want the log level and the feature flags to change without a restart when the process gets SIGHUP. One team owns the service.
