# Data shapes

For a design that stores or sends records: a table, a file format, an event, a wire payload, persisted state. Shape the records before the operations. Model the Domain (`tstack:principles`) picks the structure; this file shapes what it holds.

1. **Index card.** Write the whole model as its nouns and their fields, on what fits an index card. Git: blob, tree, commit, ref. TigerBeetle: account, transfer, ledger. A model that overflows the card holds a noun that is two things, or a field that is a second model.
2. **Identity.** For each noun, choose one and write why. A **caller key**: a business id the caller recomputes after a crash, so a retried create reaches the same thing (Temporal's `workflowId`, TigerBeetle's `id`, Stripe's idempotency key). A **content address**: the hash of the bytes, for immutable content; it dedupes and verifies itself (git objects). An **assigned id**: generated by the store, only when nothing retries the create. **Check:** a caller that crashed after sending sends again with the same key and gets the same thing back. What a duplicate create does is a named policy: fail, return the existing one, or replace it. Delivery is stated as it is: at least once plus this key.
3. **Facts.** A record is immutable. A change is a new record with its time; a correction is a reversal (Datomic's datoms, TigerBeetle's transfers, git's commits). What must mutate is one small table of names that point at facts (git's refs). **Check:** a read takes "as of" and returns the same answer tomorrow. List every field that is overwritten: each has a reason, or becomes a fact. **The cost:** storage grows and current state is derived. A cache or a derived view stays mutable.
4. **The rule's own record.** Choose the record the domain states its rule in, so the shape enforces the rule. A TigerBeetle transfer debits one account and credits one, so the books balance with no check. **Check:** name the domain's main invariant, then try to write a record that breaks it.
5. **Closed shape.** Variants are a finite named set (git has three file modes). Fields are fixed and typed; a quantity is an integer in its smallest unit. Extension is one named slot the system stores and indexes and never interprets (TigerBeetle's `user_data` and `code`). **Check:** count the optional fields. Each becomes a named variant, the slot, or a record of its own.
6. **One shape in the core.** The core knows the current shape only. An older version is a pure transform at the edge, one small module per change, applied in sequence (Stripe's dated API versions). The same holds for a stored format: upgrade on read. **Check:** a search of the core for a version number or a legacy branch finds none.
