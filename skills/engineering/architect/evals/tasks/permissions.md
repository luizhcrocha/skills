Design a permissions module for a TypeScript service that several teams' HTTP handlers and background jobs call. Resources form a hierarchy (organization > project > document). Users get roles on a resource, and a role on a parent applies to its children. Handlers ask whether a user may perform an action on a resource, and list pages need "which of these 500 documents can this user read". Admins grant and revoke roles; a revoke takes effect on the next check. An audit must answer "why could this user do this, on that date". Postgres is available; checks are on every request, a few thousand per second.
