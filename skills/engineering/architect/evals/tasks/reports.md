Design the scheduling module for recurring reports in a TypeScript service. Users schedule a report to run on a recurrence such as "every weekday at 08:00" or "the first Monday of each month", in their own time zone, and pause, resume, edit or delete a schedule. Each run produces one report file and emails a link to the schedule's recipients. A run that was missed while the service was down runs once when it comes back, not once per missed occurrence. Users see each schedule's next three runs and its past runs with their outcome. Several service instances run at once; Postgres is available. About 20,000 schedules.
