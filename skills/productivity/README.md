# Productivity

General workflow tools, not code-specific.

- **[memo](./memo/SKILL.md)** — Durable knowledge for every later session: deliberate one-line notes that will still be true in a month and are in no code, doc, commit or plan, each in one scope (repo, machine, group or user), a start read of at most 14,000 bytes at session start, supersede and retire, and compaction tasks whose summaries quote the notes they keep. Work in progress goes to its owner (a dossier, a fleet ledger, an issue), not to memo.
- **[recall](./recall/SKILL.md)** — Two modes. Lookup: what we know or what happened before, from memo's notes, `jj log` and the archived claude-mem database (read-only), as a short cited answer. Catch-up ("catch me up", "where did I leave off"): Reader miners (roles in [models.md](../../docs/models.md)) read this project's recent session transcripts, the live state (jj, PRs, `fleet waiting`, designers' dossiers, fleet ledgers) checks them, and a brief comes back: capsule, tagged threads, problems, next move. Catch-up adapted from poteto's pstack.
- **[reflect](./reflect/SKILL.md)** — `/reflect`: three Reviewers (judgment, tooling, divergent) read this session's transcript, a Decider as synthesizer sorts their findings into Accepted / Rejected / Backlog, and what you approve lands as one jj change in the skills repo for you to review; durable facts become memo notes and the backlog becomes issues. Adapted from poteto's pstack.
- **[show-me-your-work](./show-me-your-work/SKILL.md)** — A decision trail for long or unattended work: a TSV log, one row per decision (what, why, evidence, result) through `log.sh`, audited against the transcript and reviewed by a fresh agent (a Decider after a long absence, else a Reviewer), whose flags end the reply. Local by default, committed when the stakes need it. Adapted from poteto's pstack.
- **[unblock](./unblock/SKILL.md)** — find what blocks a session and what it blocks, and ask each owning agent for the action that clears it; `/heads-up` runs it, and a stalled session reaches for it.
- **[unslop](./unslop/SKILL.md)** — Cut AI tells from prose that ships (docs, commit and PR messages, READMEs, skill text, memo notes, replies under /tuca-mode): about thirty numbered rules other skills cite. Adapted from poteto's pstack.
- **[technical-writing](./technical-writing/SKILL.md)** — Layered standard for documents people read: pick the Diátaxis mode, then Google developer style, STE instruction rules and Global English. Adapted from poteto's pstack.
- **[automate-me](./automate-me/SKILL.md)** — `/automate-me`: mine your recent Claude Code transcripts (the projects you name, Reader agents over batches of your own turns) for corrections, rejected defaults and repeated instructions, and propose edits to `/tuca-mode`, its playbooks and the global `CLAUDE.md` as jj changes for you to review, each rule citing its sessions; mechanical rules come back as lint, hook or script proposals. Refines the one mode, never makes another. Adapted from poteto's pstack.
- **[grill-me](./grill-me/SKILL.md)** — Get relentlessly interviewed about a plan or design until every branch of the decision tree is resolved.
- **[free-rein](./free-rein/SKILL.md)** — `/free-rein [duration] [tell <agents>]`: give this agent free rein for a while (24h by default): it ships its finished work without asking, takes its own picks, and hands you one script with the permissions it needs; optionally it relays the same to other agents.
- **[grilling](./grilling/SKILL.md)** — Get interviewed relentlessly, one question at a time, down every branch of the decision tree until you reach shared understanding. The engine behind `grill-me`, `grill-with-docs`, `triage` and `improve-codebase-architecture`.
- **[handoff](./handoff/SKILL.md)** — Compact the current conversation into a handoff document so another agent can continue the work.
- **[heads-up](./heads-up/SKILL.md)** — `/heads-up`: a session reports on itself: done, doing, blocked, waiting on you, and loose ends; when nothing is left it offers cleanup, then suspends with `fleet suspend me`.
- **[fork-tab](./fork-tab/SKILL.md)** — `/fork-tab [idea]`: when a session drifts from its task onto a new idea, the idea moves to a fresh agent (Opus high, under tuca-mode) in a Rex tab beside this one. Its edits move to its own jj workspace, a handoff file names the skills to load, and the session goes back to its task. The light sibling of spin-off: no proposal, no designer.
- **[orchestrate](./orchestrate/SKILL.md)** — Fan a batch of pending tasks out across subagents, a dynamic workflow, or an agent team, partitioned by file ownership so workers never conflict, with shared coding standards baked into every worker prompt.
- **[deliver](./deliver/SKILL.md)** — Put a file, page or running app in front of Luiz on the device he is using. It checks whether he follows from a remote Rex client, then picks the channel: `peek` for a file he previews with Quick Look (Cmd+Y on the URL beside the path; Markdown, Word documents and spreadsheets served as HTML), an Artifact for a page that changes across versions, a tailnet URL through `tailscale serve` for a running app, Taildrop for a file he keeps.
- **[show-me](./show-me/SKILL.md)** — Explain the current topic visually with the smallest view that makes the point: pseudocode, call trees, component trees, file trees, Mermaid diagrams, diffs, or a focused HTML artifact.
- **[rename-yourself](./rename-yourself/SKILL.md)** — `/rename-yourself [name]`: the agent names its session after the work, renames its own Rex tab with `rex window rename`, and types `/rename <name>` into its own pane through `rex send`, so the tab bar and `claude --resume` show the same name.
- **[teach](./teach/SKILL.md)** — Teach a new skill or concept over multiple sessions using a stateful teaching workspace grounded in a mission, trusted resources, learning records, and a glossary.
- **[bro](./bro/SKILL.md)** — `/bro` the moment a message doesn't land: the agent says it again like one human to another, simpler and shorter, with the context you're missing, in Simplified Technical English and your `CONTEXT.md` vocabulary. Merges pstack's bro into mattpocock's wait-what.
- **[sharpen](./sharpen/SKILL.md)** — Make a task deeper, not bigger, then rewrite the prompt. From poteto's pstack.
- **[ketchup](./ketchup/SKILL.md)** — `/ketchup`: catch you up on what changed in the chat since your last message, in plain words and small visuals, then list every call waiting on you with what you need to decide it from the reply alone. From poteto's pstack.
- **[ketchup-video](./ketchup-video/SKILL.md)** — `/ketchup-video`: the `/ketchup` catch-up as a short subtitled slide video, with the waiting calls as text under it. From poteto's pstack.
- **[in-your-own-words](./in-your-own-words/SKILL.md)** — `/in-your-own-words`: the agent restates what it thinks your goals are and the problem you are solving, so you can check it understood. From poteto's pstack.
- **[writing-for-agents](./writing-for-agents/SKILL.md)** — Writing documents for agents: skills, AGENTS.md/CLAUDE.md, and any doc an agent reaches by a pointer.
